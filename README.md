Restaurants have their rules written down. Staff don't read them. frunt turns a restaurant's own documents (allergen guides, SOPs, compliance paperwork) into staff training and instant answers. Managers use the web app, staff use the phone app, and every answer shows where it came from.

> [!NOTE]
> frunt is an [MGKCodes](https://mgkcodes.com) product, so its code is private. This repo is its case study. I'm happy to walk through the code on a call: [mattykay2002@gmail.com](mailto:mattykay2002@gmail.com)

## Six parts, one system

I designed, built and run all of it: two apps, a website, an admin console, an Instagram studio and an outreach engine.
